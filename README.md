# 🌐 نظام تقليل الهدر المالي (Financial Waste Reduction System)
**الإصدار الاحترافي المتكامل (v6.0 PRO)**

## 📌 نبذة تعريفيّة عن المشروع
تطبيق ويب متكامل (Full-Stack Web Application) مصمم خصيصاً لمساعدة الأفراد على إدارة شؤونهم المالية بذكاء، تتبع الدخل والمصروفات، مراقبة الميزانية الشهرية، والحد من النفقات غير الضرورية (الهدر المالي) من خلال تحليلات برمجية ورسوم بيانية تفاعلية دقيقة.

## ⚙️ التقنيات المستخدمة (Tech Stack)
* **Backend:** Python & Flask
* **Database:** SQLite
* **Frontend & UI:** HTML5, Jinja2, Tailwind CSS
* **Visualizations:** Chart.js
* **Features:** نظام رفع الصور الشخصية (Avatars)، تصدير CSV، وتقارير طباعة مجهزة بصيغة PDF.

## 🚀 أبرز الميزات والخصائص الرئيسية
1. **نظام المصادقة والأمان:** تسجيل الدخول، إنشاء حسابات جديدة، وإدارة الجلسات بشكل آمن.
2. **الملف الشخصي الاحترافي:** رفع صور شخصية حقيقية وتخزينها محلياً، مع متابعة إحصائيات الحساب.
3. **تسيير المعاملات (CRUD):** إضافة وحذف الإيرادات والمصروفات وتصنيفها بدقة.
4. **مراقبة الميزانية:** شريط تقدم تفاعلي يتابع نسبة استهلاك الميزانية الشهرية وينبهك عند تخطي الحدود.
5. **التحليلات المرئية:** مخططات دقيقة لتوزيع التدفقات المالية والمصروفات حسب الفئات.
6. **البحث والتصدير:** إمكانية البحث السريع، الفلترة، تصدير البيانات كملف CSV، أو طباعة التقرير كملف PDF.
