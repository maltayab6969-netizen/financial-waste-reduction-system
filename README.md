# financial-waste-reduction-system
هو تطبيق ويب متكامل (Full-Stack Web Application) مصمم خصيصاً لمساعدة الأفراد على إدارة شؤونهم المالية بذكاء، تتبع الدخل والمصروفات، مراقبة الميزانية الشهرية، والحد من النفقات غير الضرورية (الهدر المالي) من خلال تحليلات برمجية ورسوم بيانية تفاعلية دقيقة. تم تطوير النظام ببنية برمجية قوية وآمنة لضمان تجربة مستخدم سلسة واحترافية.
